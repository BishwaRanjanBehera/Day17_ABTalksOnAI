🚗 Data Deep Dive: Is E85 Flex-Fuel Actually Worth It?

I ran the numbers on a 53-trip fuel dataset comparing Petrol, E85, Diesel, CNG, and EV — using my own car (Honda Accord LX, 10 yrs, ~1200 km/month city driving) as the benchmark.

The E85 Paradox:
E85 costs ~18% less at the pump than Petrol... but delivers ~13% lower mileage due to lower energy density. Net result? Running cost is actually 2.6% higher per km than Petrol (₹6.37 vs ₹6.21/km).

📉 Break-even point: E85 only makes financial sense if priced below ₹79/L (vs current ₹82/L avg).

Where E85 does win:
✅ Lowest CO₂ emissions of all 5 fuel types (0.069 kg/km)
✅ Lowest maintenance cost/km (₹0.43)
✅ Fast refuel time (~5 min, same as petrol)

The bigger picture across fuel types:
🔋 EV — cheapest to run by far (₹1.75/km) but slowest to "refuel" (~45 min)
🌿 CNG — solid budget + emissions balance (₹3.34/km)
⛽ Diesel — best for long hauls, but highest maintenance burden as vehicles age
⛽ Petrol — most convenient, but costliest to run long-term

Composite score (cost + CO₂ + refuel time + maintenance, weighted):
E85: 5.7/10 | EV: 7.4/10 | CNG: 6.3/10 | Diesel: 3.5/10 | Petrol: 3.0/10

Takeaway: E85 is a genuine environmental upgrade, but not yet a financial one — unless you can access it below ₹79/L. For pure cost efficiency, EV and CNG still lead the pack.

Built an interactive dashboard to visualize the full breakdown (cost curves by vehicle age, CO₂ comparison, break-even analysis). Happy to share the methodology if anyone's curious. 📊
